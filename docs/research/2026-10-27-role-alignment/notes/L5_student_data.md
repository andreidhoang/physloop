## 2. Facts ledger

### KQ1 — NVIDIA's student path: PR #42, PR #45, Edge

**Takeaway.** PR #42 is a three-stage recipe. Only stage 1 needs 128 H100s; stages 2 and 3 are explicitly one node (8×H100), which is exactly S5's budget shape. Stage 1 already contains an open-loop, token-level on-policy distillation of the student's own reasoning text. S5's closed-loop, state-visited correction of the action head is still unclaimed. The student's action head is trained on logged trajectories, not on teacher actions. No stage publishes a step time; NVIDIA's separate training-efficiency chapter implies ≈ 6.3k H100-h for a 100k-step 2B stage 1, likely a lower bound for PR #42. Edge is still not public.

### KQ2 — On-policy correction methods and a minimal one-node design

**Takeaway.** The two NVIDIA closed-loop methods differ in kind. RoaD uses **no teacher**: the logged trajectory guides selection among the policy's own samples. OPTED uses a **render-free** RL teacher, which makes labelling nearly free (13.5 s against 524 s of collection per 32-scene iteration). S5's 10B teacher needs rendered images, so it gives up OPTED's labelling advantage. Labelling is still small next to collection (inference), and AlpaSim's ASL logs already hold the exact observations to label. LLM on-policy distillation (GKD, MiniLLM, Thinking Machines) is token-level and is already in PR #42 stage 1. No source applies a 10B VLA teacher to the states a driving VLA student visits in closed loop (dated check, 2026-10-27).

### KQ3 — Flow-step reduction

**Takeaway.** A K ladder at inference on a fixed expert is a pure measurement. Consistency, shortcut, MeanFlow and reflow are training changes. NVIDIA's own deployment uses K = 5 with fixed noise (PR #45), FlashDrive uses 8 with velocity reuse, the code default is 10, and DRaFT tunes through 10. For an unmodified flow-matching expert, one Euler step returns the conditional mean, which collapses multimodality (§4 L5-3).

### KQ4 — Reasoning-budget control

**Takeaway.** The clean manipulation is a **cap on the same checkpoint** (budget forcing), with the realized length logged. Per-budget RL (L1/LCPO, ThinkPrune) changes the model and so breaks the plan's "architecture fixed" condition. NVIDIA's TacitVLA (2026-10-13) shows that most of the closed-loop benefit of reasoning can come from **training-time** supervision, with the action expert never reading the reasoning at inference. Truncating reasoning that the expert was trained to read can be worse than none (LLM evidence). The curve therefore confounds information value with truncation shift unless a control separates them.

## 4. First-principles rationale per finding

**L5-1 (reuse NVIDIA's stage-2 trainer as the learner).**
- *Mechanism.* DAgger's guarantee comes from training on the learner's own state distribution d_π; the learner itself is ordinary supervised regression on (state, label) pairs. NVIDIA's stage 2 is exactly that regression for this architecture, run on frozen VLM conditioning with a flow loss. The `target_action` hook swaps logged targets for teacher targets without touching model code.
- *Why it beats the alternatives.* Writing a learner from scratch duplicates a tested, parity-checked trainer. Unfreezing the VLM confounds two variables and costs ≈ 10× more per step. OPTED (decoder only) and AlpaGym (expert only) also correct the head alone, so this is NVIDIA's own pattern.
- *Cost.* Zero new GPU spend (inside S5's node window). It saves the hours of writing a learner; it costs an adapter if Edge differs.

**L5-2 (decomposition control).**
- *Mechanism.* Stage 1 regressed the head onto logs. A DAgger arm with teacher labels changes two things at once: the states (on-policy) and the targets (teacher instead of human). RoaD keeps human-anchored targets and changes only the states. Comparing the two arms against base isolates each effect.
- *Why it beats the alternatives.* Without it, a positive A2 could come from imitating the teacher's style rather than from correcting compounding error. That is the very mechanism S5's Why cites (T²ε → Tε).
- *Cost.* One arm: one collection plus one sweep.

**L5-3 (anchored, paired K ladder).**
- *Mechanism.* Euler integration of the learned velocity field has local error O(h²) and global error O(h). Under a fixed initial noise, fewer steps move the sample monotonically away from the K → ∞ solution, but closed-loop score need not follow.
- *CPU known answer* (extends `03` §4 S5): 1-D flow from N(0, 1) to N(0, 0.5²), independent coupling, marginal velocity v(x, t) = x·(−(1 − t) + 0.25t) / ((1 − t)² + 0.25t²). Euler endpoint std for K = 1, 2, 4, 5, 8, 10, 16, 32 is 0.0000, 0.2000, 0.3405, 0.3692, 0.4148, 0.43078, 0.4557, 0.4774. Squared relative std error: 100%, 36.0%, 10.2%, 6.84%, 2.90%, 1.92%, 0.79%, 0.21%. The K = 10 row reproduces `03`'s 0.43078 / 1.92%.
- *K = 1 collapse.* At t = 0 the marginal velocity is E[x₁] − x₀, so one Euler step returns the mean of the target distribution: multimodal futures (left or right) average into one. That is why one-step planners (GoalFlow, LAP) add goals or latents, and why consistency, shortcut and MeanFlow need training.
- *Why add K = 5 and reuse-4.* K = 5 is NVIDIA's deployed Thor setting, so its closed-loop cost is the production-relevant number. Reuse-4 against uniform K = 4 holds NFE fixed and varies only the schedule, which tests FlashDrive's "middle steps are nearly constant" claim in closed loop.
- *Common random numbers.* They make every arm pair share its noise, cutting the variance of paired differences, which is the gate's own currency.
- *Cost.* Two sweeps.

**L5-4 (clean CoC-budget curve).**
- *Mechanism.* The expert reads the KV of the prompt plus the generated CoC. Capping at n changes (a) the information the expert receives and (b) the distribution of its conditioning, which during training always held full CoCs. Broken Chains shows (b) can dominate in LLMs. TacitVLA shows the gain can live in the backbone (training-time), so (a) may be small.
- *Design.* Budget forcing on a fixed checkpoint varies only n, with the realized length logged. Caps above the natural length are inert (CoTinyVLA), so the informative range is set by the measured natural distribution (≈ 16 tokens in the family). The optional budget-randomized expert SFT puts every n in-distribution for the expert; the difference between the two curves estimates (b).
- *Why not L1 or ThinkPrune.* They retrain the VLM per budget or per penalty, which breaks "architecture fixed", costs RL compute, and changes what is measured.
- *Cost.* Logging only, plus one optional expert-only run.

**L5-5 (aggregation as a measured pipeline).**
- *Mechanism.* DAgger's dataset is a growing union over rounds. Correctness depends on keys (no duplicate or leaked states) and reproducibility (every label traceable to the student, teacher, simulator and seed that produced it). Cost depends on which stage binds.
- *The ASL logs* already hold the exact observations, so offline replay labelling needs neither re-rendering nor a new storage format. Inference: at ≈ 2.2 MB of raw new frames per tick at 320×576 × 4 cameras (JPEG much less), a 512-rollout FIFO is tens to low hundreds of GB.
- *NVIDIA's metrics* (mean wall clock, severe stall, OFU) are the ones its Alpamayo team uses, so the evidence is directly legible to them. This is D2/X3/D4 evidence measured on a real loop, not described.
- *Cost.* Instrumentation plus a couple of GPU-hours of micro-benchmarks. Without it, S5's cost line stays "unmeasured".

**L5-6 (A1 rule and chunk-aware manifest).**
- *Mechanism.* Contamination is about the teacher's training partition, and the `alpamayo_aligned` labels encode it per clip. The `alpasim` label marks the closed-loop pool that S5 itself trains on, so A1 uses `test` only. Download cost scales with distinct chunks touched, not with clips used: 644 scattered clips × 4 cameras is ≈ 5 TB of chunks for ≈ 0.05 TB of clip bytes.
- *Trade-off.* Chunk-aware selection can correlate with collection time or place, hence the ★ bias check.
- *Cost.* Hours only.

**L5-7 (batched driver).**
- *Mechanism.* A single-stream driver is memory-bound: decode reads all weights per token, and the expert at B = 1 runs at low arithmetic intensity. Batching concurrent sessions amortises weight reads until compute binds (`04` §4: Alpamayo's expert crosses into compute-bound at B* ≈ 4.4).
- *Why now.* Timing depends on shapes and bytes, not weight values, so the PR #42 architecture (public VLM + random-init expert) gives a true latency and throughput curve before any student checkpoint exists. Edge or a checkpoint drops into the same adapter.
- *Why it beats the alternatives.* It is the integration NVIDIA's challenge spec demands (concurrent calls, 16 GiB), it serves both S3 (16 GiB check) and S5 (collection throughput), and it measures something.
- *Cost.* A few GPU-hours.

**L5-8 (S3 fallback re-scope).**
- *Mechanism.* A pilot-scale stage 1 stops before the recipe's on-policy phase (step 75k) and far before convergence, so its verdict describes an undertrained model, not NVIDIA's student. Full scale is ≈ 6.3k H100-h (a lower bound) and a possible race with an unreleased "Nano" model.
- *The alternative.* Measuring NVIDIA's own deployment levers (K = 5 with fixed noise, CoC cap) on the released teacher answers a production question with the gate today and supplies G3·R7 ladders.
- *Cost.* It saves ≈ $1.2–1.5k and 10–20 h relative to a pilot.

**L5-9 (token-level distillation at visited states).**
- *Mechanism.* PR #42's open-loop on-policy distillation corrects the reasoning on logged states. Closed-loop states are where the student's reasoning is off-distribution. Teacher scoring is one forward pass per state (Thinking Machines: no teacher generation needed), so the dense per-token signal is cheap.
- *Caveat.* It trains the VLM, a separate variable from L5-1, so it runs after L5-1 and only if A3 matters to Huy.

**L5-10 (few-step distillation, gated).**
- *Rationale.* It pays only if the ladder shows the latency-feasible K is past a cliff. Shortcut models need one network and one phase. Consistency distillation needs teacher ODE trajectories. MeanFlow is from scratch with a JVP memory cost.

**L5-11 (decode micro-benchmark).**
- *Mechanism.* Random access into GOP-compressed video decodes from the previous keyframe, so cost scales with GOP length (PyNvVideoCodec: 37 vs 78 FPS for random 30-frame sampling at GOP 250 vs 30). NVIDIA's own loader decodes 30–50 frames for a 24-frame sample.
- *Cost.* One measurement on A1's path; X3 evidence; ≈ 1 GPU-h.
