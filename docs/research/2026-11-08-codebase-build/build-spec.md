## 1. Verification ceiling (state it in each module docstring)

- **L1** pure logic with literal known answers and negative controls; fully verifiable on CPU.
- **L2** code that targets an upstream interface (AlpaSim, alpamayo1.5 driver, AlpaGym, Cosmos-RL, Vast CLI); checked against pinned source text and hash-checked fixtures; untested on a host.
- **L3** behaviour only an admitted host establishes; ships as a plan/template/script whose report says `qualify_on_host`, never `passed`.

A green CPU suite is not `HOST_QUALIFIED`, `ACTUAL_INPUT_QUALIFIED` or rental readiness.

## 2. Shared engineering contract (binding on every module)

1. **Artifacts.** Every emitted JSON artifact has `artifact_kind`, `schema_version`, `scope` (`synthetic` | `public_source_fixture` | `actual`), producer identity (module + source hash where available), input artifact hashes, units, and `issues`. Unknown versions and missing required fields fail closed.
2. **Statuses.** `passed`, `blocked`, `not_run`, `not_estimable`, `unverified`, `not_applicable`, `qualify_on_host`. Absence is never a pass; missing is never zero.
3. **Issues.** `{code, path, severity, evidence_refs, message}`; stable snake_case codes.
4. **Filesystem.** Confine paths to a declared root; reject traversal, absolute external paths, symlink escapes, duplicate normalized names; verify bytes at consumption; no-follow reads where evidence is concerned.
5. **Secrets.** No credentials in artifacts, logs, argv or subprocess/profiler environments. Environments are allowlisted. Tests use synthetic canaries, never real secrets. Tokens are referenced by environment-variable name or file path supplied at run time, never embedded.
6. **Effects.** Pure functions where possible; inject filesystem, process runner, clock and provider clients at effectful boundaries; CPU tests use fakes. No default path provisions, funds, accepts terms, downloads gated assets or launches workloads. Any executing path requires an explicit recorded-authority input and refuses without it.
7. **Owner inputs.** Huy's values are required fields with no defaults: scenes, roads/strata, margins, tolerances, seed modes, reward arm and learning settings, evaluated-path estimand, retry-selection and missing-data rules, terminal semantics, camera fix, Harmonizer pinning, predictions, criteria such as the E07 pass criterion. Unregistered → `blocked` naming the field. Never choose them.
8. **Protected files.** Never edit `gate/verdict.py`, `gate/stats/`, `.claude/`. Import protected inference; never copy or re-implement it.
9. **Upstream.** Wrap shipped code; never fork NVIDIA's trainer or simulator. P-032's driver variant and RNG coupling are not built. Vendored upstream source used as a test reference is byte-identical, hash-checked, stored with its LICENSE and a `provenance.json` (repo, commit, path, sha256), and only specific AST nodes are executed with a restricted namespace (pattern: `tests/test_alpasim_ground_truth_upstream.py`).
10. **Determinism.** Canonical JSON via `gate.s2_identity.identity_hash`/`canonical_json_bytes`; no wall-clock values inside hashed content; sorted iteration where order is not semantic.
11. **Tensor identity convention (shared by `gate/tensor_manifest.py` and `teacher_rl/params.py`).** A tensor's identity hash is SHA-256 over its raw bytes in the stored dtype, row-major contiguous, little-endian — exactly the byte range a safetensors file stores for it — plus separately recorded dtype string (safetensors names: `F64, F32, F16, BF16, I64, I32, I16, I8, U8, BOOL, F8_E4M3, F8_E5M2`) and shape. A hash computed from a loaded tensor must equal the hash of its stored byte range.
12. **Code style.** Python 3.12; numpy/scipy/pyarrow/protobuf already locked; torch/safetensors only under `teacher_rl` torch-dependent modules and `tests/s4_torch/`; no other new dependency without a requested shared change. Module docstring states purpose, ticket IDs, verification ceiling and what the module never does. Ruff clean at line length 100.

## 3. Build rules for agents

- **Tests first.** Each acceptance item has at least one literal known answer and one negative control that must be rejected. Oracles are independent of the implementation (hand-derived literals, exhaustive enumeration, or hash-checked upstream source executed as the reference).
- **Run only your own tests while building**: `PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B -m pytest -p no:cacheprovider -q <your test files>` (torch tests: prefix `PHYSLOOP_REQUIRE_TORCH=1`) and `.venv/bin/ruff check --no-cache <your files>`. Other agents edit other files concurrently; do not run the whole suite.
- **Ownership.** Create or edit only your module's listed files. Shared files (`gate/s2.py` CLI, `gate/__main__.py` unless listed, `pyproject.toml`, `uv.lock`, CI, `scripts/rehearse_s2_pilot.py`, `docs/` except where listed, `DOC_AUTHORITY.md`) are integrated serially by the coordinator: return the change you need as a requested shared change. Keep existing public functions backward compatible unless your module spec says otherwise; if an existing test encodes a defect you fix, change that test and explain why.
- **No** git commit/branch/stash/push, no network calls except where a module explicitly allows public source reads into the scratchpad, no rental, no license action, no gated download, no edits to existing `evidence/`.
- **Safety rule (verbatim in every brief):** *No test may invoke a real `vastai`, `docker`, `hf`, `huggingface-cli`, `nvidia-smi`, `nvidia-ctk`, `uv lock`/`uv sync` on an upstream checkout, or any network call. All subprocess and provider calls go through an injected runner/client; a test that shells out to a real tool is a defect, not a convenience.* The `vastai` and `gh` CLIs on this Mac may be authenticated.
- **Refused writes.** If the harness refuses a file write, return the exact content as a requested shared change; never route around a refusal through the shell.
- **Agent technical defaults** (allowed under D-018, e.g. a 12 h watchdog hard bound, a 2026-09-22 attestation floor, a provisional ASL size bound) are labelled `agent technical default (D-018)` in docstrings so Huy can see what he inherits.
- **Vendoring licence check.** Before copying any upstream file into `tests/fixtures/`, confirm the repository's LICENSE permits redistribution and copy it alongside; if it does not, store path, line references and SHA-256 only and re-derive.
