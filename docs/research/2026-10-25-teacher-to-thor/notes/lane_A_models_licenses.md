## 2. Deltas since 2026-10-03

- **PR #42, alpamayo-recipes (10-20, open, unmerged).** Distillation recipe that takes AM-1/AM-1.5 down to about 2B: a `nvidia/Cosmos-Reason2-2B` student VLM plus a compact action expert, then Stage-2 expert SFT and Stage-3 DRaFT RL.
  - Data: PAI-AV, pinned to revision `2ae73f49`, plus LingoQA.
  - Resources: "At least 128 NVIDIA H100 GPUs" recommended, and ≥100 TB of storage.
  - Results: R1.5-2B with the 2-stage expert reaches full-PAI-val minADE6 0.8875 m against 0.8298 m for the teacher (+6.95%).
  - "Closes: #20" (the community distillation request).
- **PR #43 (10-20).** Domino and DFlash2 draft models for speculative decoding of AM-1.5 and its distills.
- **PR #45 (10-21).** TensorRT inference for the 2B AM1.5/AM1 distills on **DRIVE AGX Thor** (DRIVE OS 7.0.5/7.2.6).
  - Median latency: 171.2 ms in FP8 (about 5.8 Hz) and 220.6 ms in FP16.
  - It uses a forked TensorRT-Edge-LLM. The upstream change is NVIDIA/TensorRT-Edge-LLM PR #260, "Alpamayo fused gate/up plugin for SM110" (10-21).
  - This is the AM-1.x 2B student, **not** Alpamayo 2 Edge.
- **GTC Berlin (10-21).**
  - Alpamayo 2 Edge: 2B, built on Cosmos, DRIVE AGX Thor, 10 Hz; blog says GitHub/HF "later this month".
  - Alpamayo Agentic Factory: open blueprint, "early 2027".
  - NIM microservices for Alpamayo 1.5 and NuRec Harmonizer; Halos SAFE (with dSPACE, IVEX, TÜV Rheinland); Cosmos 3 Nano variants.
  - Bolt selected the Alpamayo Stack: ≥25,000 L4-capable Lucid vehicles, Madrid in 2027. Volvo and Mercedes are on Hyperion and the Stack.
- **alpamayo-recipes main, 10-06: reasoning-reward sign fix** (#40, issue #29). The reasoning term in `aggregated_reward_with_reasoning` was sign-inverted, so GRPO was rewarded for worse CoT agreement. Any RL result produced from the open-loop recipe before 10-06 is suspect.
- **alpamayo-recipes main, 10-16:** data moved to a shared `data/` directory. The gold-644 eval metadata `1005_7cam_gold_eval_metadb_public.parquet` is public there.
- **AlpaJudge is public** and absent from the baseline. HF repo created 09-02, README edits 10-08/10-09/10-23; GitHub NVlabs/alpajudge created 09-18. Weights OpenMDW-1.1, code Apache-2.0.
- **PAI-AV v26.10** (repo lastModified 10-23). Splits moved to `splits/`, and a new `splits/alpamayo_aligned.parquet` "adds a split aligned with Alpamayo training data". This matters for contamination and split choice in the gate. It needs physical_ai_av ≥ 0.2.3. A 26.09 entry fixes offline calibration for 140 clips; its date relative to the baseline is unknown.
- **New dataset PhysicalAI-Autonomous-Vehicles-Foundation4D** (10-15): 1,253 clips with depth, occupancy and semantic labels. It is "for non-commercial uses only".
- **Unchanged:**
  - The three model cards (last edits 08-04/08-07). The 1.5 card still reads AlpaSim 1.37 ± 0.10 (913 scenarios); Super reads 1.50 ± 0.13.
  - No new nvidia Alpamayo models on HF.
  - arXiv 2511.00088 is still v2 (2026-01-07).
  - PAI-AV and NuRec license §1/§3/§4.6/§8 wording.
- **Hyperion 10 lidar count conflicts within NVIDIA.** The 2026-09-10 NVIDIA blog says "three lidars"; the Oct 2025 release said "one lidar".
- **Minor.** NVlabs/alpamayo2 commit on 10-07 (VQA/auto-label text extraction). The Super card is internally inconsistent: "2B diffusion expert" in one place, "Action Expert: 2.3B parameters" in another.

No. As of 2026-10-25 NVIDIA has published no Alpamayo 2 Edge weights, no Edge card and no Super→Edge recipe: HF returns 401 for every Edge name, and no repo exists in NVlabs or NVIDIA.
